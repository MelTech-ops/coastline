# Coastline Property Holdings LLC — Website

Static site (HTML/CSS/JS, no build step). Preview with GitHub Pages.

## Edit before launch
Open `script.js` → `CONFIG`:
- `FACEBOOK_PAGE_URL` — client's Facebook Page URL (turns on the live feed + Follow/Review buttons)
- `EMAIL` — business email (shows on the contact card, powers the contact form)

Replace the placeholder reviews in `index.html` (search for "Client review goes here").

## Logo
`assets/logo-dark.svg`, `assets/logo-light.svg`, `assets/mark.svg`, `assets/favicon.svg`

## Publish preview
Settings → Pages → Deploy from branch → `main` / root.
